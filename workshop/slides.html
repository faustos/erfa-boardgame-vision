A flat board seen at an angle: a 3×3 matrix with 8 unknowns. Each corner gives 2 equations (x and y), so 4 corners = 8: exactly enough. engine/warp.js · warp()

A2 · Similar pictures point the same way

export function cosine(a, b) {
  let dot = 0;
  let aa = 0;
  let bb = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    aa += a[i] * a[i];
    bb += b[i] * b[i];
  }
  return aa && bb ? dot / Math.sqrt(aa * bb) : 0;

engine/fewshot.js · cosine(): 1 = same direction, 0 = unrelated

B1 · The Set rules in code

const area = cv.contourArea(contour);
const hull = new cv.Mat();
cv.convexHull(contour, hull);
const solidity = area / Math.max(1, cv.contourArea(hull));
hull.delete();
const rect = cv.minAreaRect(contour);
const boxFill = area / Math.max(1, rect.size.width * rect.size.height);
const shape = solidity < SQUIGGLE_SOLIDITY ? 'squiggle'
  : boxFill < DIAMOND_BOX_FILL || boxFill > RECTANGLE_BOX_FILL ? 'diamond' : 'oval';
export function colorOfHue(h) {
  if (h >= 60 && h < 200) return 'green';
  if (h >= 200 && h < 330) return 'purple';
  return 'red';
}

solutions/set.js · readShape(), colorOfHue()

  • White balance first: each pixel ÷ the card's paper colour. Yellow lamp or shade, the paper is white again.
  • Ink = how far the darkest channel is below white; Otsu splits ink from paper.
  • Solidity = area ÷ convex hull: a squiggle has dents. Box fill: a diamond fills half its box.
  • A wrong read is fixed by moving a threshold, not by more data. Live video: 10 frames vote (steady).

B2 · References: Sudoku compares each cell

  1. Cell → black-and-white ink mask, cut to the ink.
  2. Shrunk to 8 × 8 = 64 numbers (pixelEmbedding).
  3. Compared with every reference (cosine, 1 = same).
  4. Closest wins (matchTile). Below 0.5: empty / not sure.

The references are digits drawn by code, a few per digit. Nothing is trained: a new digit style = a new reference.

B3 · The fingerprint and the catalogue

// A card's fingerprint: the shapes of its fields, e.g. ".#..,####,##..|###,###,#..". Null without two fields.
/** @param {{ grid: string[] }[]} fields */
export function fingerprint(fields) {
  return fields.length === 2 ? fields.map((f) => f.grid.join(',')).join('|') : null;
}

solutions/ubongo.js · # = square, . = none, , = next row, | = second field

  • Memory: “Card looks right ✓” saves fingerprint → card type + pieces per roll in localStorage. Next time the fingerprint alone names it; &card=A24 pre-confirms one.
  • Catalogue (engine/pieces3d.js): every turn of every piece, as cubes seen from above. A blob gets the best-scoring piece of its colour, no piece twice.
  • Live video: anchor holds a confirmed card, steady votes over frames.

C2 · The loop in code

async function liveFrame() {
  const now = performance.now();
  const mode = settings();
  if (!limiter.ready(now)) return;
  // A 64×48 grey thumbnail says if anything moved since the last change.
  const moving = change.update(greyThumb(grabFrame(video, THUMB.width, THUMB.height)), now);
  if (change.still(now) > IDLE_MS) return pause('Nothing changed for 2 minutes: camera off to save battery.');
  // Searching: every frame. Found: with the hand check on, detect() only after a move; else when the picture moved.
  // An anchored card (engine/anchor.js) is only tracked inside the game's detect(): cheap, so it may run each time.
  if (!detectNow({ searching: searching && !ui.hand, detectNext, hands: Boolean(stopHands), skip: mode.skip, moving, hasResult: Boolean(lastResult) })) return;
  detectNext = false;

When you are stuck

  • Board not found: better light, a plain table, More → Tap corners, or a print sheet (print.html).
  • Wrong names: more reference tiles on tiles.html (about 3 per name).
  • Labels flicker: the steady and anchor blocks, or freeze the picture (snowflake).
  • 15 minutes on the same problem: wave. Finished versions of every starter are on the branch solutions; there, add &solution to the address.
  • Own game does not work out: switch to a starter. Tic-Tac-Toe is the quickest.
