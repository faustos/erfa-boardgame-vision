# Set: the owner's real photos (28 Oct 2026)

Two layouts of 12 cards (`deck-a-*`, `deck-b-*`), each from two angles, on a dark wood table in evening light.
Used for the slide screenshots (#121) and as a harder test for `solutions/set.js`.

This deck prints **rectangles** where most Set decks print diamonds. The truth files call them `diamond`
(same role in the game: the third shape).

Part of the required replay test (`tests/replay.test.js`, `REQUIRED_FOLDERS`, issue #124) and of the Sample photos
(`replay/set/samples.json`). Run: `node replay/run.js set/owner --solution`.
